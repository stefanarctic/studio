# **App Name**: PhotoText Extractor

## Core Features:

- Image Upload: Provide an intuitive interface for users to upload or drag-and-drop images.
- Text Extraction: Utilize an OCR tool API to automatically detect and extract text from the uploaded image.
- Text Display: Display the extracted text in a clear, editable text box below the image, allowing users to copy the text.

## Style Guidelines:

- Primary color: White or light gray for a clean background.
- Secondary color: Dark gray for text and UI elements to ensure readability.
- Accent: Teal (#008080) for buttons and interactive elements.
- Simple, single-column layout for easy navigation.
- Use clear, recognizable icons for upload and copy functions.
